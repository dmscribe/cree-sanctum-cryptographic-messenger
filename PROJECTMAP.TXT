Cree Sanctum Cryptographic Messaging — Project Map
Author: Daniel Scribe — github.com/dmscribe

Purpose:
- One line per product file or directory describing what it does.
- Tracks the current source tree for the desk, crypto, docs, and native headers.
- Omits dependency/build caches and transient outputs such as node_modules, dist,
  .output, .vercel/output, artifacts logs, and screenshots.

/
- .tanstack/ — TanStack Start generated runtime and type artifacts for routing/build.
- attachments/ — reference images and pasted text used while designing or documenting the app.
- cpp/ — reserved C++ workspace area for future native-side code or packaging support.
- docs/ — product documentation, diagrams, and security analysis.
- libpgpbind/ — C++ header-only device-binding interface used by the cryptographic core.
- libsanctum/ — C++ header-only Sanctum protocol and cryptographic core interfaces.
- libsuggest/ — C++ people-you-may-know suggestion engine and its tests.
- migrations/ — SQL schema and data migrations for auth, messaging, desk, and discovery state.
- public/ — static web assets served directly by the app.
- sanctumd/ — native daemon entrypoint that mirrors Sanctum server-side behavior.
- scripts/ — local build, preview, env, migration, and test helper scripts.
- server/ — runtime server middleware used by the built TanStack/Nitro app.
- src/ — React/TanStack Start application source, routes, UI, and server helpers.
- .env — local developer environment values; ignored so secrets are not committed.
- .env.example — committed template for local environment configuration.
- .gitignore — ignore rules for secrets, caches, build output, and local-only files.
- .node_modules.lock — npm install lock marker used by the workspace/package tooling.
- .prettierrc — Prettier formatting rules for the repository.
- .project_id — local workspace/project identifier metadata.
- eslint.config.mjs — ESLint configuration for TypeScript, React, and script files.
- LICENSE — Apache 2.0 license text for the dual-licensed project.
- LICENSE-MIT — MIT license text for the dual-licensed project.
- LOCAL.md — short local developer runbook for booting Cree Sanctum.
- Makefile — native C++ helper targets such as tests, bench, and archive tasks.
- package-lock.json — exact npm dependency lockfile.
- package.json — project metadata, scripts, and npm dependency manifest.
- README.md — main product overview, local setup steps, and security references.
- startup.sh — local startup helper that boots the dev server and records pid/log files.
- tsconfig.json — TypeScript compiler configuration.
- vite.config.ts — Vite/TanStack Start config, React plugin wiring, and security headers.
